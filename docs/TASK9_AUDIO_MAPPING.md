# TASK 9 — AUDIO MAPPING

The foundation reuses existing audio only. The door-close variant definition is used as a brief, quiet cue in five guarded encounter functions. Dead Forest, Crypt Depths, and Nightmare Zone intentionally remain silent at trigger time to preserve anticipation and prevent repetitive audio.

| Region | Audio identity | Implementation |
|---|---|---|
| Abandoned Outskirts | Sparse distant cue and silence | Existing door-close cue, volume 0.18 |
| Dead Forest | Wind/silhouette/long quiet periods | No new cue; silence preserved |
| Cemetery District | Restrained supernatural movement | Existing door-close cue, volume 0.14 |
| Abandoned Hospital | Empty-building tension | Existing door-close cue, volume 0.16 |
| Cursed Village | Sparse abandoned-settlement cue | Existing door-close cue, volume 0.12 |
| Old Laboratory | Isolated mechanical tension | Existing door-close cue, volume 0.12 |
| Crypt Depths | Extremely sparse low activity | No new cue; silence preserved |
| Nightmare Zone | Unusual high tension and long silence | No new cue; silence preserved |

No music, screaming, new audio source, generated asset, particle, or tick loop is introduced.
